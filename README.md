## Tujuan Praktikum
1. Memahami konsep dasar Database.
2. Memahami konsep CRUD menggunakan PHP.
3. Membuat program CRUD sederhana menggunakan PHP.

## Langkah Praktikum

### 1. Persiapan
Menyiapkan XAMPP, Visual Studio Code, Apache dan MySQL.

### 2. Membuat Database
Membuat database dengan nama latihan1.

### 3. Membuat Tabel
Membuat tabel data_barang dengan kolom:
id_barang, kategori, nama, gambar,
harga_beli, harga_jual, dan stok.

### 4. Menambahkan Data
Memasukkan tiga data barang elektronik ke database.

### 5. Membuat Koneksi Database
Membuat file koneksi.php untuk menghubungkan PHP dengan MySQL.

### 6. Menampilkan Data (Read)
Membuat index.php untuk menampilkan data barang.

### 7. Menambah Data (Create)
Membuat tambah.php untuk menambahkan barang.

### 8. Mengubah Data (Update)
Membuat ubah.php untuk mengubah data barang.

### 9. Menghapus Data (Delete)
Membuat hapus.php untuk menghapus data barang.
